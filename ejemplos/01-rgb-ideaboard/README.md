# Ejemplo 01 · LED RGB de la IdeaBoard

Tu primer programa en C para la placa: el LED RGB pasa por rojo, verde, azul y blanco, y luego hace
un arcoíris. Si mantienes **BOOT** presionado durante el arcoíris, el LED se apaga.

**Aprendes:** estructura de un programa ESP-IDF (`app_main`), funciones, `while`, `for`,
esperas con `vTaskDelay` y `printf` por USB.

**Materiales:** solo la IdeaBoard y un cable USB-C de datos. No hay que conectar nada.

**Paso a paso completo:** [guía para correr C](../../docs/guia-correr-c.md#5-tu-primer-programa-en-la-ideaboard-el-led-rgb).

**Estado:** ✅ probado en una IdeaBoard real (el LED cambia de color y el Monitor muestra
`Hola desde la IdeaBoard!`).
